# Spring Boot Task Manager

A REST API for creating, updating, completing, and deleting tasks.

## Tech stack
- Java 17+
- Spring Boot
- Maven
- REST API
- JUnit

## Run
```bash
./mvnw spring-boot:run
```

Or, if Maven is installed:
```bash
mvn spring-boot:run
```

## API
See the controller classes for available endpoints.
